Set up your dashboard

About 10 minutes. Everything you enter stays in this browser (localStorage) — nothing is sent anywhere except the two services below.

1

Supabase

Open Supabase ↗

Create a free project, then in SQL Editor paste and run setup.sql once. Copy these two from Settings → API. The anon key is public by design — never paste a connection string or service-role key here.

2

Relay

Deploy on Render ↗

Deploy the relay with the Deploy to Render button (see the repo README / docs/setup.md), then paste its URL. It must end in /relay — this is the same URL your team pastes into CardMirror.

3

Dashboard token — optional, enables invites / viewing / editing

The dashboard's own relay token. Simplest: paste your relay's shared RELAY_TOKEN. For per-person tokens, generate one here and add it to RELAY_TOKENS (role coach).

Add a session

Paste the share code a partner sent you. We keep only the room ID (segment two). The encryption key (segment three) is discarded — that is what makes it impossible for this dashboard to read student work.

Team tokens

Add or remove people; each gets a per-person relay token. This list lives in this browser only. To apply changes, either Sync to relay (instant, needs coach sign-in + relay-tokens.sql) or Copy RELAY_TOKENS and paste it into Render (one redeploy).
