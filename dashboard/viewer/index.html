Room name viewer (v3 · opt-in)

This page decrypts document content in your browser to read each room's first heading (H1). It only works for rooms you paste a share code for — the code carries the key. The key stays here and is never sent to Supabase. Requires enable-viewer.sql to have been run. Because it can read student work, use it deliberately.

Config is remembered in this browser (localStorage), shared with the main dashboard.
